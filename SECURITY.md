# Security policy

Please do not publish exploitable boot-path, parser, installer-helper, or
firmware-update vulnerabilities in a public issue before coordinated review.
Contact the project owner through the security channel published at
[apex32-secure.com](https://apex32-secure.com).

Include the affected commit, firmware/OS environment, reproduction steps, and
whether physical access is required. Never attach private signing keys,
recovery keys, or machine-specific firmware-variable dumps to a public report.

The `0.10.0-alpha` line is development software and is not yet supported for
production installation.
